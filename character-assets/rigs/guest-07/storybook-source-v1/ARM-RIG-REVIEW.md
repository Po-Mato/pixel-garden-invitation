# 7번 팔 원본 리그 수정

상태: 검수 중. 운영 승인이나 다른 캐릭터의 팔 승인으로 사용하지 않는다.

## 수정 이유

기존 소매 꼭대기 부착점은 어깨에서 원화를 매달아 놓은 인상을 만들었다.
또한 손바닥 쪽 원본 좌표를 공용 hand 관절에 연결하여 소매와 손목 경계가
공용 분할선에서 어긋났다. 정면에서는 팔꿈치·손목의 직선 절단도 드러났다.

## 원본 편집 위치

- body-registration.json: 네 방향 여덟 개 팔의 sourcePivot은 소매 내부의 어깨 부착점,
  sourceEnd는 손목/소매 끝으로 직접 지정했다. 공용 골격의 pivot과 targetEnd는 변경하지 않았다.
- joints/: 각 원화에 연결된 위팔·아래팔·손의 24개 SVG 마스크.
  곡선 팔꿈치와 손목 경계를 사용한다. 그림을 포함하지 않는 편집 가능한 원본이며
  등록된 원화를 마스킹한 뒤 부모 관절 회전으로 출력한다.
- 소매와 손의 원화 PNG 및 원본 알파 매트, 머리·몸통·치마·가방 원화는 수정하지 않았다.
  완성 프레임의 픽셀을 복사하거나 보정하지 않았다.

## 범위와 검수

새 마스크는 7번에만 등록했다. 나머지 리그는 기존 렌더 경로를 유지한다.
공용 렌더러 수정 후 나머지 11명의 생성 PNG 해시가 같아야 한다.
관절 연결 수치만으로 외형 통과를 결정하지 않는다. 정면·측면·후면의
어깨 부착, 소매 길이, 손목 연결과 가방의 손 부착을 실제 표시 크기로 확인한다.
보행 키프레임과 머리 72 / 몸 144 / 전체 216 규격은 변경하지 않았다.
