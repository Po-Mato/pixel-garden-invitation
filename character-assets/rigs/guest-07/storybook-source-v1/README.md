# 7번 라벤더 쉬폰 원본 리그 연구

운영 미반영. 네 방향 원본 파츠와 공용 보행 16프레임의 로컬 연구 검수 완료.
현재 reference/guest-directions/feminine-lavender-jacket-dress/down.png의
밤색 옆가르마, 오른쪽 어깨로 흐르는 웨이브, 진주 귀걸이, 라벤더 쉬폰 원피스,
착용자 왼손 아이보리 가방을 유지한다. 5번 참고안은 그림체 기준이다.

기존 7번 리그가 1번 머리와 5번 의상 파츠를 참조함을 확인한 뒤 해당 방향
원본을 표시했다. 내장 이미지 생성으로 개별 파츠만 생성하며 별도 과금 API는
사용하지 않는다. 공용 머리72/몸144/전체216 골격을 유지한다.

정면 머리 원본: 세션 01a054aa-c737-7ec3-9535-c8a8f6768a91,
생성 ID 6764c3ef-dec4-4a95-bcf5-b7383ea8e207.
얼굴·앞머리·뒷머리의 편집 가능한 소유 경계를 지정하고 전체 원본을 균일 등록한다.
최종 프레임의 일부 픽셀을 수선하지 않는다.

## 조립 및 검수

- 머리 72 / 몸 144 / 전체 216, 캔버스 192×288, 공용 관절 유지.
- 방향별 몸통·팔·치마는 각각의 원화. 오른쪽 머리의 먼 쪽 웨이브만 몸통 뒤에 배치.
- 36개 몸통 파츠 등록. 팔은 어깨와 손바닥 중심의 두 점으로 균일 등록하고
  위팔·아래팔·손 / 허벅지·종아리·신발은 공용 관절 소유 영역과 피벗을 따른다.
- 정면과 후면 몸통의 균일 등록 배율은 각각 실제 어깨 연결을 확인해 0.055로 지정.
  후면 팔 끝은 공용 손 관절 x=73/119에 연결. 골격이나 출력 픽셀은 바꾸지 않았다.
- 긴 치마는 공용 painted-long-skirt-v1 키프레임 사용. 2/4 중립 동일, 1/3 반대 발 전진.

  클러치는 착용자 왼손 소유이며 왼쪽 보기에서는 몸통/치마에 가려진다.
- review.html에서 390×844, 네 방향, 재생/정지, 96×144 및 48×72 표시를 확인.
  generated/mobile-*.png 및 browser-review.json은 연구 페이지 증거다.
- 실제 선택 UI·게임 맵·서비스 워커·전체 릴리스 검증은 아직 수행 전이다.
  runtimeEligible=false와 visualApproved=false를 유지하며 배포 성공을 뜻하지 않는다.

# 원본 명암 레이어 시험

정면 치마에만 `sources/skirt-front-edge-shading-v1.svg`를 등록했다.
원본 좌표에서 편집하는 벡터 명암이며, 리그 등록 전에 source-atop으로
합성한다. PNG 패치나 프레임별 보정이 아니고 원본 알파는 정확히 보존한다.
방향별 외형·비율·골격과 다른 캐릭터는 변경하지 않았다.

동네 맵 정면 중립의 대비는 1.087 → 1.125로 개선됐지만 기본 기준
1.17에는 미달한다. 전체 화면 조건 미달은 19 → 16건이다. 이 시험은
시각 승인이나 배포 승인이 아니며, 추가 진하게 만들기와 일괄 적용은 하지 않았다.
실제 횡단보도 화면은 `../../storybook-expansion-v1/client-guest-7-crosswalk-front-source-shading.png`.
