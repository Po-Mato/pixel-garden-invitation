# 2번 여성 한복 원본 연구

제작 중, 운영 미반영. 기존 원화의 갈색 옆가르마 낮은 올림머리,
착용자 왼쪽 아이보리 꽃 머리핀, 작은 진주 귀걸이, 크림 저고리와
분홍 치마 및 노리개를 유지한다. 공용 머리72/몸144/전체216 골격 사용.
한복 의상 움직임은 femaleHanbok 공용 동작을 사용하며 원피스와 구분한다.
최종 PNG 수정 및 단순 좌우 반전 금지. 별도 과금 API 사용 없음.

내장 이미지 생성 세션: 01a054aa-c737-7ec3-9535-c8a8f6768a91.

- 정면 머리: 2bdd279f-5f04-4d43-bd7e-c675fd15a467
- 방향별 기존 원본을 먼저 표시하고 개별 파츠만 생성한다.
- 프롬프트: 기존 정체성, 5번의 귀여운 게임 명암, 절제된 머리 볼륨,
  머리와 머리카락만, 투명 배경. 꽃핀은 착용자 왼쪽 유지.

네 방향 머리·저고리·치마·양팔과 공용 다리, 노리개를 연결한 16프레임 연구.
구조 검사 15개 통과, 390×844 연구 페이지 네 방향/재생/정지/표시 크기
검수 완료. 실제 선택 화면·맵·서비스 워커 검수는 남아 있다. 운영 미반영.
