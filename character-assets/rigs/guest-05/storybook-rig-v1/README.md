# 5번 동화풍 정면 · 편집 가능한 원본 리그

승인된 `../storybook-concept-v1/front-concept.png`를 디자인 참고로 삼은 **정면 중립 프로토타입**이다. 운영 자산이나 완성된 4방향 보행 리그가 아니다. 기존 리그·소매 후보·맵 대비 기준·운영 파일은 변경하지 않았다.

## 원본과 생성물

- `front-art.svg`: 직접 작성한 벡터 원본. 23개의 이름 있는 독립 그룹으로 구성되어 각 경로·색·그라데이션을 수정할 수 있다. 래스터 이미지를 삽입하거나 승인 원화를 잘라 붙이지 않았다.
- `front-rig.json`: 각 그룹의 부모 관절과 공용 골격 피벗, 정면 중립 포즈, 비대칭 방향 명시.
- 공용 골격 `../../common-three-head-216-v1/skeleton.json`을 그대로 참조하며, 관절 위치·팔/다리 길이를 캐릭터별로 자동 보정하지 않는다.
- `generated/`: SVG 원본에서 자동 출력한 중립 PNG, 축소 PNG, 파츠별 SVG 사본, 생성 기록, 검수 페이지. 이 폴더의 PNG를 수정하거나 제작 원본으로 쓰지 않는다.

분리 파츠: 얼굴(귀·눈·눈썹·입 포함), 앞머리, 뒷머리, 목, 몸통 상의, 볼레로 몸판, 좌우 위팔·아래팔·손, 골반, 치마, 좌우 허벅지·종아리·신발, 리본, 가방, 그림자.

## 검수

- 캔버스 192×288, 머리 측정 구간 y54~125=72px, 머리 아래~발 기준선 144px, 전체 불투명 캐릭터 y54~269=216px. 발 기준선 y270.
- 머리는 기존 공용 리그와 같은 두개부 측정 구간을 사용한다. 턱 아래로 내려오는 번 헤어 끝은 두개부 높이에 포함하지 않는다.
- 18개 테스트: 파츠 분리·원본 제약·정확한 골격·배경 알파·흰 의상 보존·14개 중립 접합부·비대칭 가방·결정적 재출력.
- 눈매가 원화보다 날카롭고 밑창이 두꺼워 보였던 첫 출력을 시각 검토 후 원본 얼굴/신발 색에서 수정했다. 출력 PNG 보정은 하지 않았다.
- 브라우저 검수는 390×844, 192×288·96×144·48×72 비교, 파츠 숨기기, 관절 표시, 어두운 배경, 전체 복원을 다룬다.

이 벡터 그림은 승인된 래스터 원화의 픽셀 복제가 아니다. 형태와 색을 참고한 재작화이며 명암·눈매·치마 길이 등 세부 표현 차이가 있다. **숫자와 연결 검사 통과를 원화 충실도 승인으로 취급하지 않는다.** 비교 페이지에서 실제 크기로 함께 검토해야 한다.

측면·후면, 4프레임 보행과 움직이는 관절 연결, 의상별 공용 애니메이션, 실제 선택/게임 통합, 맵 대비 및 운영 배포는 이번 단계에서 구현·검증하지 않았다. 앞선 소매 폭 후보의 맵 대비 회귀가 해결되었다는 의미도 아니다. 커밋·푸시·배포 없음.

```sh
node scripts/render-guest05-storybook.mjs
node scripts/build-guest05-storybook-review.mjs
node --test scripts/guest05Storybook.test.mjs
node scripts/capture-guest05-storybook-review.mjs
```

브라우저 검수 후에는 `agent-browser --session storybookrig05 close`로 해당 세션만 닫는다.
