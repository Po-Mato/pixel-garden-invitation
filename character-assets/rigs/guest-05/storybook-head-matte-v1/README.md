# 정면 머리: 래스터 원본 + 편집 가능한 마스크

사용자가 별도 과금 없는 로컬 원본 마스크 편집을 승인하여 제작했다.
원본은 `../storybook-head-study-v1/front-head-candidate.png`이며 그대로 보존한다.
승인 전신 원화와 동일한 그림은 아니므로, 이 머리 파츠의 스타일 재현 승인까지 받은 것으로 취급하지 않는다.

## 제작 구조

래스터 파츠 RGB + `head-matte-refined.svg`의 편집 가능한 윤곽 → 자동 렌더링 → `generated/head.png`.
이전 수작업 `head-matte.svg`는 이력으로 보존한다.

- `node scripts/render-storybook-head-matte.mjs`로 재생성한다.
- 원본 RGB는 전 픽셀 그대로 유지하며 피부·눈·머리결을 벡터로 다시 그리지 않는다.
- 알파는 원본 마스크가 결정한다. 외부 반투명 찌꺼기를 원본 윤곽 밖으로 제외하고 내부는 불투명으로 출력한다.
- 완성 보행 프레임을 입력으로 사용하거나 수정하지 않는다. 신체 영역 복사, 프레임별 변형, 골격 변경이 없다.
- 좌우 반전이나 다른 캐릭터에 동일 마스크 대입을 하지 않는다.
- 수정은 마스크 원본에만 적용하고 자동 재출력한다. 첫 검수에서 옆머리 안쪽 틈의 잘못된 영역을 발견해 해당 원본 윤곽을 수정했다.

## 검수

`generated/audit.json`에 입력·마스크·출력 해시와 원본 RGB 불변 검사 결과를 기록한다.
`generated/review.png`: 열은 흰색 / 어두운 청회색 / 맵 유사 녹색. 행은 머리 높이 약 288 / 72 / 36 / 18px.
72px는 고해상도 머리, 36px는 96×144 표시, 18px는 48×72 표시의 머리에 해당한다.
현재는 머리만 검수하며 전체 캐릭터 캔버스의 배치·크기 검증을 대신하지 않는다.

내부 반투명 결함이 해결됐고 원본 RGB 불변 검사가 통과했다. 옆머리 안쪽의 검은 채움도 마스크 수정 후 제거했다.
확대 시 턱 윤곽 및 가는 잔머리 경계는 추가 정밀 검수가 필요하다. 전체 원화와 인상 일치, 얼굴·앞머리·뒷머리 독립 파츠, 네 방향 골격 등록, 보행은 아직 미완료다.
따라서 운영 연결·배포·11명 일괄 적용은 하지 않았다.

## 정밀 윤곽 및 관절 등록

수작업 윤곽에서 원본의 약한 알파 영역까지 덮은 3080px을 발견했다. 원본의 주 불투명 연결 영역을 참고해 독립 마스크를 다시 작성했다.
`scripts/trace-storybook-head-matte.mjs`는 한 번의 원본 마스크 작성 보조 도구다. 출력 SVG를 검수 후 저장하며, 렌더러는 이 추출을 실행하지 않는다.
추출 기준 alpha 240은 원본의 선을 찾는 작업용 기준이며 검사 허용치 변경이 아니다. 렌더링 결과의 색은 원본 RGB와 동일하다.

`head-registration.json`에 목 부모, 피벗, 원본 정수리/턱 위치, 균일 배율을 지정했다. 머리 기준 높이는 72px이고 가로·세로를 따로 늘리지 않는다.
`generated/head-registration-192x288.png`와 96×144, 48×72 결과는 머리만 배치한 시험 프레임이다. 전체 캐릭터 완성물이 아니다.
`generated/reference-comparison.png`는 왼쪽 승인 전신 원화와 오른쪽 머리 후보의 머리 높이를 약 152px로 맞춘 비교다. 원화는 통째로 표시하며 파츠 재료로 자르거나 사용하지 않았다.

## 보이는 표면의 세 레이어 분리

`head-layers.json`의 편집 가능한 경로로 얼굴 / 뒷머리(보이는 쪽머리) / 앞머리를 구분했다.
`node scripts/render-storybook-head-layers.mjs`가 원본 래스터와 원본 마스크를 읽어 레이어 PNG 및 검수 자료를 자동 생성한다.
머리 PNG 완성물을 잘라 붙이는 과정이 아니라, 동일한 원본 텍스처에 각 레이어의 원본 마스크를 적용하는 방식이다.

세 레이어의 부모는 head, 원본 피벗은 [735,1009]로 고정한다. 다른 상대 이동은 허용하지 않는다.
첫 검수에서 얼굴 영역에 포함된 쪽머리 부분을 원본 경로에서 줄였다.
`generated/layers/parts-review.png`는 왼쪽부터 얼굴 / 뒷머리 / 앞머리이다.
`generated/layers/assembled.png`는 실제 출력된 세 PNG를 다시 합성한 결과다.

검증: 소실된 알파 없음, 합성 알파 완전 일치, 불투명 영역 RGB 완전 일치.
반투명 경계에는 실제 합성 반올림으로 RGB 최대 1 차이가 관측되었다. 따라서 모든 출력 픽셀의 완전 동일성을 주장하지 않는다.
이 수치는 렌더링 동작의 측정값이며 시각 품질의 합격 기준을 대신하지 않는다.

중요한 한계: 현재는 보이는 표면만 분리했다. 머리카락 뒤 이마·가려진 뒷머리를 새로 그리지 않았다.
얼굴 경계의 가는 머리 선 등 레이어 소유권 정밀 검수도 남는다.
독립 스킨 교체나 머리카락만의 움직임을 지원하는 완전한 파츠 세트가 아니다.
독립적인 파츠 원화 완성 전에는 이 구성으로 11명의 얼굴·머리 교체를 완료했다고 보고하지 않는다.

## 2026-09-12 숨겨진 이마 보완

- 분리 PNG에서 alpha=0 영역에도 통합 머리 RGB가 남는 것을 확인했다. 렌더러가 해당 투명 영역의 RGB만 0으로 출력하도록 수정했다. 입력 원본과 보이는 픽셀은 유지한다.
- 내장 imagegen으로 피부 원화를 추가했다. `sources/hidden-forehead-paint-v1.md`에 원본과 프롬프트를 기록했다.
- `hidden-forehead-matte.svg`는 피부만 포함하는 편집 가능한 원본 마스크다.
- `node scripts/render-storybook-hidden-forehead.mjs`로 자동 출력한다. 앞머리가 완전히 가리고 기존 얼굴 픽셀이 없는 영역에만 피부 원화를 등록한다.
- `generated/hidden-forehead/review.png`: 숨은 피부 / 앞머리 없는 얼굴 / 전체 조립 결과 순서다.
- 실제 레이어 재합성 결과, 앞머리를 켠 외형은 이전 조립 결과와 RGBA 전 픽셀 동일하다. 앞머리를 끄면 이마와 숨은 눈썹이 나타난다.
- 아직 얼굴에 남은 갈색 머리 경계의 소유권 정리, 숨은 뒷머리 원화 및 독립 동작 시각 검증이 필요하다. 독립적인 머리 교체나 11명 확장 완료를 의미하지 않는다.

### 얼굴/앞머리 경계 수정

제외 경로를 evenodd로 합친 구현은 얼굴 밖에서 XOR처럼 픽셀을 추가했다. 흰 포함 경로에서 검은 제외 경로를 실제로 빼는 마스크로 수정했다.
머리선 안쪽으로 얼굴 경로를 정리하고 숨은 피부 마스크를 관자놀이·귀 연결 영역까지 확장했다.
앞머리를 끈 검수에서 굵은 갈색 잔머리가 사라졌고, 켠 결과는 이전 조립 결과와 동일하다.
이마의 얇은 색 연결선 및 귀 부근 경계는 확대 검수에서 계속 주의가 필요하며, 새 머리 스타일의 독립 교체 검증은 아니다.
`node --test scripts/storybookHeadLayers.test.mjs`로 실제 재출력 후 투명 RGB 정리, XOR 재발 방지, 원래 외형 보존, 숨은 피부 샘플 및 미승인 상태를 검사한다.
