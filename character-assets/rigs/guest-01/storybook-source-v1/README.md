운영 미반영. 네 방향 16프레임 출력 중이며 최종 시각 승인 전이다.

표시했다. 기존 측면 reference PNG가 정면의 반쪽이어서, 방향 확인에는 기존
`guests-style-lock-v1/guest-01/parts/{left,right,back}` 파츠도 직접 표시했다.

## 네 방향 조립

측면·후면 상의는 각각 별도 원화이며 원본 전체 균일 배율만 사용한다.
