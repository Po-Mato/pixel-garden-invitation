## 긴 치마의 다리 가림

이후 확대 보행 검수에서 치마 옆으로 허벅지/종아리가 비치는 현상을 확인했다.
6번에만 sources/long-skirt-leg-visibility.svg를 의상 레이어로 연결했다.
공용 골반에 붙은 가림 영역은 밑단 안쪽 y=248부터 발·발목을 노출하며,
원래 다리 파츠 전체, 피벗, 보폭, 키프레임은 보존한다.
완성 프레임 픽셀을 자르거나 복사하는 작업이 아닌 원본 리그의 가시성이다.
다른 긴 치마 캐릭터에는 자동 적용하지 않았다.
회귀 검사는 의상 밖인 허리 위(y<171)와 발목·신발(y>=248)의 픽셀이
가림을 끈 진단 렌더와 정확히 같은지 검사한다. 기존 팔 모바일 증거는
이 추가 가림 전 자료이며 머리·팔·발의 외형 비교에만 유효하다.

운영 미적용. `runtimeEligible=false`, 시각 승인 및 보행 검수 미완료.
공용 골격: 머리 72 / 몸 144 / 전체 216px, 192×288 캔버스.
긴 머리의 끝이 아니라 정수리–턱을 머리 높이로 등록한다.

## 편집과 검수 경계

원본 PNG + 편집 가능한 SVG 실루엣 + 명시적 피벗 등록으로 렌더한다.
`sourceSamplesPerOutputPixel=2`는 원본 전체 레이어의 축소 샘플링이며,
골격·피벗·길이를 변경하거나 최종 PNG의 픽셀을 수선하지 않는다.
흰색/크림색 의상은 색상 키로 제거하지 않는다.
완성 프레임의 머리·어깨·발 복사, 프레임별 비율 보정은 사용하지 않는다.

추가 가방 원본: 오른쪽 `29f55385-0a80-415a-a071-ad1e9feabfb0`,
왼쪽 `08f65adb-2efd-4836-8d4b-707085569d2a`. 앞 잠금장치가 있는 바깥쪽과
무장식 안쪽은 각각 그린 파츠다. 네 방향 모두 착용자 왼손 부모 관절을 유지한다.
후면 머리 후보 `505c172e-de0b-421a-9440-b918c2b056ea`도 지나치게 길어 미적용.
후면 원본의 숨겨진 턱 등록선은 950, 정수리는 40으로 재검토했다.
전체 원본을 균일 등록하며 공용 72px 머리 관절 규격은 변하지 않는다.

긴 뒷머리는 몸 뒤, 얼굴과 앞머리는 몸 앞에서 합성한다. 원본 마스크에
24 source-pixel 숨김 겹침을 명시했다. 겹침은 원래 실루엣 안으로 제한하고,
최종 프레임을 수정하지 않는다. libvips 검정 전경 규칙 때문에 white-alpha
확장은 `erode`이며, 반대 연산으로 생기던 밝은 경계선을 회귀 검사로 고정했다.
네 방향의 기존 불투명 머리 내부는 분리 합성 뒤에도 정확히 alpha 255다.
