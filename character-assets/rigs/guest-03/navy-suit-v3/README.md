# 3번 네이비 정장 사람형 컷아웃 파일럿 v3

v2의 몸·정장·보행 골격은 유지하고, 사람처럼 읽히지 않았던 얼굴·머리·목만 방향별 원본 파츠로 다시 설계한 파일럿이다.

- `heads/raw/`: 내장 이미지 생성 도구로 만든 방향별 머리 파츠 보드
- `heads/clean/`: 바깥 배경만 제거한 중간 산출물
- `heads/parts/`: 얼굴·앞머리·뒷머리·목 편집 파츠
- `part-layout.json`: v2 몸 파츠와 v3 머리 파츠를 결합하는 192×288 배치
- `rig.json`: v2 보행 리그를 상속하는 v3 원본 정책

완성 보행 프레임은 생성하지 않았으며, 출력 PNG를 직접 수정하지 않는다.
문제가 생기면 `scripts/prepare-guest03-human-head-parts.mjs`의 원본 파츠 선택·배치 또는 `rig.json`을 수정하고 다시 렌더링한다.
