# 하객 캐릭터 v1 검수 알파 마스크

v9 원화 중 투명 배경처럼 보이는 체크 패턴이 실제 RGB 픽셀로 들어간 9종의 인물 실루엣 마스크다.

- 대상: `guest-01`, `guest-03`, `guest-06`~`guest-12`
- 크기: 원본과 같은 1086 × 1448px
- 흰색은 인물, 검은색은 배경, 회색은 가장자리 부분 투명을 뜻한다.
- 흰 소매·셔츠·크림색 정장처럼 배경과 색이 가까운 복장은 인물 인식 결과와 어두운 배경 비교판을 함께 검수했다.
- 색상 임계값으로 흰 픽셀을 삭제하지 않는다. 불투명 v9 원화에는 이 마스크가 없으면 v10 빌드가 실패한다.

`scripts/build-guest-safe-source-sheets.mjs`가 원본 RGB에 이 알파를 적용하고, 이전 밝은 배경색이 가장자리에 번지지 않도록 부분 투명 픽셀의 색을 인물 안쪽 색으로 정리한다.
