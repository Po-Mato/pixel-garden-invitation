# 하객 4방향 고품질 시안 v3

이 폴더의 이미지는 운영 캐릭터에 연결하지 않은 검토용 원본 시안이다. 단순 벡터 골격으로 디테일을 잃지 않고도 상하좌우 방향의 크기와 발 기준선을 안정적으로 맞출 수 있는지 먼저 확인한다.

## 시안

- `guest-02-turnaround-pilot.png`: 로즈 여성 한복. 원본의 얼굴, 땋은 올림머리, 꽃장식, 한복 자수와 노리개를 유지한다.
- `guest-03-turnaround-pilot.png`: 네이비 클래식 수트. 원본의 얼굴, 검은 가르마 머리, 수트 재질과 넥타이를 유지한다.

## 운영 전 승인 조건

- 네 방향 모두 같은 카메라와 중립 자세를 사용한다.
- 캐릭터 전체만 균일 비율로 축소·확대할 수 있으며, 방향별 또는 신체 일부 늘이기는 금지한다.
- 실제 192×288 프레임 조립 단계에서 공통 콘텐츠 높이와 발 기준선을 적용한다.
- 이 두 시안의 얼굴·의상 디테일과 비율을 승인하기 전에는 나머지 10종을 일괄 생성하지 않는다.
