# 하객 평면 3등신 시안 v4

이 폴더는 운영 자산에 연결하기 전 승인된 **검토용 12종 시안**이다. v3는 네 방향의 전체 높이만 맞췄고 실제 머리:몸 비율과 입체 렌더링을 제한하지 못했으므로 교체 후보에서 제외한다.

## 고정 3등신 기준

- 검토 캔버스: 방향당 `384×576px`
- 정수리: `y=24`
- 턱 아래 목 접점: `y=192`
- 발바닥: `y=528`
- 머리 1칸: `168px`
- 턱 아래 몸 2칸: `336px`
- 전체: `504px = 168px × 3`

후면에는 턱이 보이지 않으므로 네 방향에서 공통으로 식별 가능한 **턱 아래 목 접점**을 1H 경계로 쓴다. 머리·몸을 따로 늘이거나 방향별로 보정하지 않으며, 생성이 끝난 시트는 캐릭터 전체만 같은 비율로 축소해 리그에 배치한다.

원본 시트는 고정 4등분하지 않는다. 투명 배경의 실제 빈 열을 찾아 네 캐릭터 그룹을 분리하므로 머리카락·가방처럼 열 경계에 가까운 디테일도 잘리지 않는다.

## 평면 2D 기준

- 일정한 외곽선과 제한된 평면 색상만 사용한다.
- 입체 조명, 연속 그라데이션 명암, 광택, 재질 하이라이트, 바닥 그림자, 3D 원근감을 금지한다.
- 최종 PNG는 투명 배경과 최대 40색 무디더 팔레트로 저장한다. 얼굴, 머리 모양, 자수와 장신구 같은 식별 디테일은 보존한다.
