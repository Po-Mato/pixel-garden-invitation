# 하객 캐릭터 v9 통일 광학 리그

하객 12명의 정체성은 유지하면서, 선택 화면과 게임에서 보이는 체형·얼굴 크기·방향별 점유율을 하나의 리그로 고정한다.

## 고정 규격

- 시트: 3열 × 4행, 총 12컷
- 열: 보행 A / 정지 / 보행 B
- 행: 정면 / 좌향 / 우향 / 후면
- 최종 프레임: 192 × 288px
- 인물 높이: 252px
- 머리 구간: 84px
- 몸 구간: 168px
- 발 기준선: y=264
- 머리 실루엣 폭: 92px, 허용 오차 ±2px
- 정면/측면 머리 실루엣 폭 비율: 0.97~1.03
- 좌/우 머리 실루엣 폭 차이: 2px 이하
- 캐릭터별 차이: 얼굴 정체성, 머리 모양, 의상, 색상, 소품만 허용
- 공통 요소: 카메라, 렌더 질감, 3등신 비율, 머리 부피, 어깨·허리·무릎·발 기준선, 프레임 점유율

체커보드가 이미지에 구워진 경우 빌드 단계에서 연결된 밝은 배경만 제거한다. 인물 픽셀은 84/168 세로 리그와 92px 머리 실루엣 정규화 외에는 변경하지 않는다.

## 재생성 지시문

> 하객 12명을 같은 리그로 전부 다시 생성해. 3×4 시트로 만들고, 열은 보행 A·정지·보행 B, 행은 정면·좌향·우향·후면으로 고정해. 모든 컷은 정확히 3등신이며 머리 부피, 얼굴 크기, 어깨·허리·무릎·발 기준선, 카메라와 프레임 점유율이 같아야 해. 정면과 측면 얼굴은 같은 광학 크기로 보이게 하고, 신랑·신부와 어울리는 부드러운 2.5D 입체 명암을 사용해. 캐릭터별 차이는 얼굴 정체성, 헤어, 의상, 색상, 소품만 허용해. 12명 전체 비교판과 자동 비율 감사를 모두 통과한 결과만 적용해.

생성 결과는 원본 방향 시안과 한 장씩 비교한다. 행 방향, 12컷 수, 3등신, 2.5D 질감, 배경 분리가 하나라도 어긋나면 저장하지 않는다.
