# 평면 3등신 하객 보행 원화 v1

검수를 마친 12종 원화는 캐릭터 선택 화면과 게임 맵에서 사용하던 기존 입체 렌더를 함께 대체한다.

- 배열: 3열(`왼발`, `중립`, `오른발`) × 4행(`아래`, `왼쪽`, `오른쪽`, `위`)
- 체형: 목 경계 위 1머리, 아래 2머리인 정확한 3등신
- 표현: 가는 외곽선과 단색 면 중심의 평면 2D 게임 일러스트. 입체 조명, 그라데이션, 광택, 질감, 그림자, 깊이감, 원근감은 사용하지 않음
- 정체성: 각 `guest-selection-pilots/v4-flat` 승인 시안의 얼굴·헤어·의상·소품을 유지
- 런타임 정규화: 선택 화면 192×288, 게임 96×144 프레임. 정수리·턱·발 가이드와 발 기준선을 전 방향에서 통일

내장 Image Gen에서는 모든 캐릭터에 다음과 같은 짧은 공통 프롬프트 구조를 적용했다.

> 승인된 캐릭터를 4행×3열 전신 보행 시트로 만든다. 열은 왼발·중립·오른발, 행은 정면/아래·왼쪽·오른쪽·후면/위다. 얼굴·헤어·의상·소품·색상·가는 외곽선과 정확한 3등신을 유지한다. 단색 면만 사용하고 정수리·턱·발을 정렬한다. 그라데이션·명암·하이라이트·광택·질감·그림자·깊이감·3D·원근감·잘림·포즈 흔들림은 금지한다.

`scripts/build-guest-selection-preview-assets.mjs`는 원본 칸의 크기를 고정값으로 가정하지 않고 투명화한 전경 간격에서 시각적 격자를 찾는다. 따라서 Image Gen이 정사각형 캔버스를 선택해도 인접 행의 머리나 발이 다른 프레임으로 섞이지 않는다.
