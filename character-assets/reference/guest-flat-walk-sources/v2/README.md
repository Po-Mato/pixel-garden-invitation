# Guest 01 and 06–08 optical three-head redraws

`guest-01`, `guest-06`, `guest-07`, `guest-08`의 방향별 체형이 다르게 보이던 문제를 보완한 원화다.

- 시트는 3열 × 4행이며 행 순서는 `down`, `left`, `right`, `up`이다.
- 각 행의 열은 앞발 전진, 중립, 반대발 전진 보행 순서다.
- 모든 컷은 정수리–턱 1단위, 턱–발 2단위의 3등신을 기준으로 한다.
- 정수리, 턱, 어깨, 허리, 치마 밑단, 발 기준선을 방향과 보행 컷 사이에서 고정한다.
- 긴 머리는 어깨와 허리선을 가리지 않도록 견갑골 부근에서 정리한다.
- 입체 렌더나 그림자를 추가하지 않고 평면 2D 게임 아트로 유지한다.

빌드 스크립트는 이 폴더에 원화가 있는 하객만 v2를 우선 사용하고 나머지는 v1을 유지한다.
