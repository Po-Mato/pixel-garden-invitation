# Guest optical face-rig redraws

`guest-01`, `guest-02`, `guest-03`, `guest-05`, `guest-06`, `guest-07`, `guest-12`의 정면 얼굴이 측면보다 과도하게 커 보이던 문제를 보완한 원화다.

- 시트는 3열 × 4행이며 행 순서는 `down`, `left`, `right`, `up`이다.
- 각 행의 열은 앞발 전진, 중립, 반대발 전진 보행 순서다.
- 모든 컷은 정수리–턱 1단위, 턱–발 2단위의 3등신을 기준으로 한다.
- 정면·좌측·우측의 피부 얼굴 폭은 전체 머리 외곽과 별도로 광학 검사한다.
- 정면 얼굴 폭은 좌우 측면 중앙값 평균의 1.35배 이하여야 한다.
- 좌측·우측 얼굴 폭 차이는 두 방향 중앙값 평균의 20% 이하여야 한다.
- 입체 렌더나 그림자를 추가하지 않고 평면 2D 게임 아트로 유지한다.

빌드 스크립트는 이 폴더의 v3 원화를 가장 먼저 사용하고, 없는 하객은 v2와 v1 순서로 유지한다.
