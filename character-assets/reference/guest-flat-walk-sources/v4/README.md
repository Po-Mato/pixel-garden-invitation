# Guest direction and motion polish v4

12종 전체의 방향 전환 품질과 보행 리듬을 한 기준으로 정돈한 원화다.

- 시트는 3열 × 4행이며 행 순서는 `down`, `left`, `right`, `up`이다.
- 각 행은 동일한 중간 보폭의 왼발 전진, 중립, 오른발 전진 순서다.
- 정수리–턱 1단위와 턱–발 2단위의 3등신으로 정규화한다.
- 정면과 측면에서 눈, 코, 귀의 높이와 얼굴 중심선이 자연스럽게 이어진다.
- 모든 컷은 같은 발 기준선과 가는 짙은 외곽선을 사용한다.
- 단색 면 중심의 평면 2D 게임 아트를 유지하고 명암, 입체 조명, 3D 표현은 사용하지 않는다.

빌드 스크립트는 v4를 가장 먼저 사용한다. 선택 화면은 192×288 프레임으로 유지하고,
실게임용 96×144 프레임에는 반 픽셀 수준으로 보이는 공통 외곽선을 적용해 48×72 표시에서
캐릭터마다 선이 흐리거나 두꺼워 보이는 차이를 줄인다.
