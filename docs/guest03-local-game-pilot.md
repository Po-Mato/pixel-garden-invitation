# 3번 캐릭터 실제 로컬 게임 연결 — 2026-09-08

## 실행

프로젝트 루트에서 `pnpm --filter @wedding-game/client exec vite --config vite.guest03-pilot.config.ts --host 127.0.0.1 --port 5193 --strictPort`.

http://127.0.0.1:5193/ 에서 캐릭터 설정 → 네이비 클래식 수트 → 닉네임 → 정원 입장. 기존 root `pnpm dev`는 전체 자산 생성 작업이 포함되어 있어 이번 검수에서는 실행하지 않았다.

별도 Vite 설정의 개발 서버에서만 3번 캐릭터를 integrated-v2에 연결한다. 192×288 원본 프레임을 선택 화면 96×144, 게임 48×72로 표시한다. 나머지 11명과 일반 실행은 기존 자산을 쓴다. public 파일을 덮어쓰거나 빌드에 파일럿 PNG를 포함하지 않는다. 시트가 없으면 503이며 다른 캐릭터로 조용히 대체하지 않는다.

## 실제 확인

- agent-browser / 390×844 / 실제 Entry 화면, 캐릭터 선택, GameWorld의 우리 집 맵.
- 12명 선택 전환: 3번만 파일럿 URL, 나머지 11명 기존 URL.
- 선택 화면 정면·오른쪽·뒷면·왼쪽 전환과 보행 정지. 실제 CSS 배경 행 0/-576/-864/-288, 중립 열 -192 확인.
- 게임 48×72 확인. 실제 가상 조이스틱에 키보드 입력 이벤트를 전달하여 상하좌우 위치 변화, 방향/시트 행 일치, 입력 종료 후 moving=false 및 0-based frame=1 복귀 확인. 플레이어 상태나 좌표를 직접 수정하지 않았다.
- 원본 16프레임 검수에 더해 실제 선택/게임 정지·후면·측면 화면을 육안 확인. 증거: character-assets/rigs/guest-03/style-lock-cutout-v1/animation/integrated-v2/local-selection.png, local-game-idle.png, local-game-back.png, local-game-left.png.
- 브라우저 페이지 오류 없음. 로컬 검수 서버에는 서비스 워커 등록/컨트롤러 없음(개발 모드 기본 동작). 시트 응답 Cache-Control=no-store. 브라우저 수신 데이터 SHA-256과 로컬 파일이 일치: `84827750596d0a1b6e32db739f3e29927911164b6d2c61e13c8fb834ad22fabe`.

## 수정 및 테스트

기존 눈깜빡임 CSS는 전용 idle 시트의 열을 바꾼다. 파일럿은 보행 시트 중립을 쓰므로 idleUrl이 있는 레이어에만 기존 idle-front 클래스를 붙이도록 수정했다. 그렇지 않으면 정지해도 접촉 자세가 표시될 수 있었다. 기존 사용자 변경은 보존했다.

클라이언트 전체 258개 파일 / 1,356개 테스트 통과. 타입 검사 및 클라이언트 프로덕션 빌드 통과. 프로덕션에서 파일럿 호출 분기가 제거되도록 마지막으로 조건 위치를 정리하고 관련 3개 파일 테스트를 재실행했다. 프로덕션 JS에 파일럿 URL/버전이 포함되지 않는지 검사한다.
