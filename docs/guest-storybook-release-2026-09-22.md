# 페인팅 컷아웃 리그 릴리스 진행

## 검수본 고정

원본 72px 머리·144px 몸·216px 전체 높이와 192×288 프레임을 유지한다.
1번은 승인된 균형형 팔 원본을 별도 `balanced-source-recipe-v3.json`으로
통합했다. 2·5·7번은 개별 방향 원본 SVG 명암만 보완했다. 완성 PNG의
머리·어깨·발 복사, 신체 영역 변형, 무조건적 좌우 반전은 사용하지 않았다.
명암 밖 원본 RGB와 16프레임 알파 윤곽을 회귀 검사한다.

- 전체 원본 검사 165개와 구조 검사 112개 통과.
- 1번 활성 원본의 목·팔 112개 연결을 기존 기본 리그 검사와 별도로 확인.
- 12명 × 10개 맵 × 16프레임 = 1,920개 기본·6개 표시 조건 대비 미달 0개.
- 대비 기준 1.17 / 1.10 유지. 실패를 숨기거나 허용치를 늘리지 않았다.
- 390×844 선택 화면의 12명 전환, 48방향 정지, 보행 재생 확인.
- 선택 192프레임, 집·동네·지하철역·열차 각각 실제 이동 192프레임의
  현재 자산 해시·방향·이동·정지를 확인.
- 12명의 선택/집 접촉 시트와 변경한 1·2·5·7번의 추가 3개 맵 접촉
  시트를 직접 시각 검수했다. 긴 의상에 가려진 관절은 원본 검사와 구분한다.
- 클라이언트 260파일 / 1,368테스트, 맵 82테스트, 전체 타입 검사 통과.

정확한 원본·출력·검수 자료 해시는
`character-assets/rigs/storybook-expansion-v1/review/release-candidate-v1.json`에
고정한다. 이는 로컬 후보 검수 기록이며 운영 배포 성공 기록이 아니다.

## 일반 빌드 연결 및 로컬 릴리스 검증

`build-active-guest-assets.mjs`가 페인팅 원본을 재렌더하고 검수본과 일치하는지
검사한 뒤에만 일반 생성기가 public 자산을 교체하도록 변경했다.
검수 후 원본·출력·시각 증거가 바뀌면 빌드를 차단한다. 과거 기하학 리그는
역사적 원본으로 보존하지만 일반 빌드에서는 호출하지 않는다.

일반 경로에서 88개 자산을 재생성했고, 12명의 선택·게임 자산은 검수본과
일치한다. 운영용 로컬 빌드에서 192개 선택 프레임과 192개 실제 게임 이동
프레임을 재촬영하고, 12명 각각의 선택·게임 접촉 시트를 직접 확인했다.
새 자산 URL 버전은 `guest-storybook-cutout-v1-20260922`이다.
구버전 48개가 캐시된 상태에서 새 48개로 교체되는 별도 로컬 SW 검사는
잔존 구버전 0개로 통과했다. 초기 오프라인 설치 84/84개와 갱신·롤백도
통과했다. 이것은 아직 운영 사이트의 갱신 성공을 뜻하지 않는다.

사진 효과 검사에서는 알파 픽셀 행 수 대신 정확한 원본 골격 평면
(축소 좌표 13.5~67.5, 높이 54px)을 사용한다. 반 픽셀 경계가 55개 행에
걸칠 수 있으므로 실제 출력 전체가 검수 원본의 축소 결과와 픽셀 단위로
일치하는 검사를 추가했다. 캐릭터 PNG나 기존 허용치를 조작하지 않았다.
맵 중심과 발 기준선도 의상·가방의 알파 경계가 아닌 공용 골격으로 고정한다.

릴리스 대상 파일만 추출하고 오프라인 의존성 설치를 한 별도 디렉토리에서
12명 재생성과 검수 해시 일치를 확인했다. 관계없는 기존 변경은 포함하지 않는다.

전체 `pnpm test` 통과: 공유 81개, 클라이언트 1,368개, Worker 262개,
시각 관련 220개, 맵 82개, 일반 캐릭터 107개, 사진 효과 3개와 원본·구조
검사를 포함한다. 별도 타입 검사 및 리소스 용량 예산도 통과했다.
새 기준선 대비 시각 회귀는 맵 10곳·캐릭터 12명 모두 0.000%이며 허용치는
기존 0.500% 그대로다. 운영용 프리뷰의 자산 버전·해시 검사 12개도 통과했다.

오프라인 재검사 1회에서 다음 맵의 선행 로딩 요청 2개가 실패했다.
핵심 캐시 84/84는 완전했으며 재검사에서는 진입·게임 재개가 통과했다.
이를 캐릭터 캐시 교체 결과와 혼동하지 않는다. 별도 교체·롤백 및
48개 구버전→48개 신버전 오프라인 검사도 재통과했다.

최종 전체 `pnpm build`도 통과했다. 릴리스 대상 파일만 추출한 별도
디렉토리에서 `pnpm install --offline --frozen-lockfile`, 재생성,
전체 `pnpm test`, 타입 검사를 재실행해 모두 통과했다.

현재 완료로 보고하지 않는 항목:

- 관련 파일만 분리한 커밋, PR, main 병합, Pages 배포
- 운영 자산 해시와 로컬 산출물 일치

동일한 맵의 선택적 캡처는 직렬로 실행한다. 병렬 실행으로 검수 JSON이
덮인 사례는 해당 캐릭터 재촬영과 전체 범위·해시 재검사로 복구했다.
Worker 코드는 변경하지 않았으며 Worker 배포는 수행하지 않는다.

## 원격 렌더링 재현성 검증

첫 Linux 검사에서 알파 윤곽은 같지만 일부 원본 명암 합성의 RGB 값이
달라 배포 게이트가 차단했다. 단순 SIMD 해제는 해결하지 못했다.
`paintedSourceOverlay.mjs`의 원본 파츠 합성에 float32 반올림 및
곱셈·덧셈 순서를 명시해 컴파일러별 차이를 제거하는 수정안을 적용했다.
참고한 연산 계약은 [libvips 8.17.3 합성 구현](https://github.com/libvips/libvips/blob/v8.17.3/libvips/conversion/composite.cpp)이다.
완성 프레임의 픽셀 보정이나 비교 허용치 확대는 하지 않았다.

수정 후 로컬 재생성 12명 전체 PNG가 최초 시각 검수본과 바이트 단위로
동일하고, 구조 검사 116개가 통과했다. 원본 입력 코드 해시가 바뀌었으므로
관절 검증의 렌더링 영수증만 재생성해 검수 기록에 연결했다.
Linux에서도 같은 결과가 나오는지는 PR 재검사로 확인하며, 그 전에는
운영 배포 완료로 간주하지 않는다.

## 병합 후 배포 게이트 재현성 보완

PR #68의 Linux 빌드와 모바일 시각 검사는 통과해 main으로 병합했다.
첫 Pages 실행 35702444824는 최종 PNG가 아닌 1번의 중간 원본 검수
이미지 `generated/front-body-study.png` 보호 해시 검사에서 차단됐다.
원인은 이 중간 이미지의 전체 원본 레이어 합성에 남아 있던 네이티브
float32 계산 차이였다. `paintedStudyComposite.mjs`로 원본 레이어의
source-over 계산을 명시하고, 기존 검수 이미지 보호 해시를 변경하지
않은 채 동일 결과를 재현했다. PR의 공용 빌드에도 원본 구조 검사를
추가해 이 검사를 병합 전에 수행한다. PNG 복사나 허용치 변경은 없다.

main의 Android 검사 및 전체 모바일 시각 회귀는 통과했다. iOS 실행
35702443649도 실제 Safari 캡처·비교는 통과했지만 최근 10회 실행의
p95 준비 시간 1435초/480초, 총시간 1567초/1200초 기준 초과로 워크플로는
실패했다. 이는 별도 CI 안정성 지표이며 통과로 바꾸어 보고하지 않는다.
Worker는 배포하지 않았다. 수정 후 재배포 및 운영 확인은 계속 필요하다.

## 운영 후 첫 보행 로딩 검수

PR #69 이후 Pages 35708096056은 전체 테스트·운영 PWA까지 통과했고,
88개 운영 PNG 해시와 구버전 캐시 교체도 일치했다. 그러나 실제 운영
화면 직접 검수에서 5번 이후 여러 캐릭터의 첫 보행 시트 로딩 중
빈 화면이 포착됐다. DOM 프레임 번호·해시만 확인하는 자동 검사는 이를
놓쳤다. 정지 배경을 보행 배경으로 즉시 바꾸는 UI 로딩 전환이 원인이다.

`CharacterSprite`는 새 시트가 준비될 때까지 이미 로드된 반대 자세의
시트를 유지하도록 수정했다. 별도 원화/출력 PNG는 변경하지 않았다.
첫 보행 다운로드를 지연하는 브라우저 검사는 기존 운영 코드에서 실패,
수정한 개발·프로덕션 빌드에서 통과했다. 시작·정지 회귀 테스트 2개를
추가해 클라이언트 1,370개와 타입 검사가 통과했다. PR 모바일 검사에도
이 지연 다운로드 검사를 추가한다. 게임 프레임 캡처는 실제 시트가 준비된
프레임만 수집하되, 대기 중 가시성은 별도 첫 보행 검사로 반드시 검증한다.
이 보완의 운영 재배포 및 최종 직접 검수는 아직 남아 있다.
