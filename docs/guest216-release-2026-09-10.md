# 216px 원본 리그 및 미리보기 릴리스 검증

## 범위

- 머리 72·몸 144·전체 216px 공용 골격, 12명 방향별 원본 파츠 → 자동 16프레임 출력 → 전체 프레임 축소.
- 선택 미리보기: 390×844에서 160×240 캔버스, 작은 높이 화면은 128×192. 수평 중심 및 바닥선 고정, 진입 애니메이션은 불투명도만 변경.
- 실제 게임: 48×72 표시 유지. 원본/최종 PNG에 신체 영역 복사 보정 없음.
- 기존 런타임의 몸/발 중첩 복사와 기존 선택 프레임 보정 생성기를 새 파이프라인으로 대체.
- Worker 코드 및 배포 변경 없음. 과거 실험 파일, 관련 없는 작업과 `.DS_Store`는 보존하고 릴리스에서 제외.

## 검수와 회귀 기준

캐릭터별 관찰은 `guest-three-head-216-visual-review.md` 참조. 최신 선택 화면 48장을 실제 표시 크기로 비교했고 5개 화면 크기 × 12명 × 4방향 240건의 중심/바닥/크기 검사를 통과했다. 이전 보행·실제 게임 증거와 정지 캡처 검수는 구분한다.

의도한 원화 전환으로 모바일 게임 기준 이미지만 갱신했다. 사용자 위임하에 Codex가 검토했으며, 종전 기준 및 실패 비교는 `character-assets/rigs/common-three-head-216-v1/release-review/legacy-baseline/`에 보존했다. 변경률 허용치와 대비 기준은 완화하지 않았다. 별도 모바일 HUD 기준은 변경 없이 통과했다.

## 로컬 릴리스 검사

- 맵 테스트 82건, 새 맵 브라우저 대비 1,920개 조합 통과.
- 일반 캐릭터 테스트 107건 및 새 리그/재질/출력 검수 통과.
- 사진 효과 12명·192프레임 및 테스트 2건 통과.
- 모바일 게임/월드 배치 시각 회귀 각각 0.000% 변경, 시각 계약 테스트 220건 통과.
- 공유 코드 81건, 클라이언트 1,368건, Worker 테스트 262건 통과.
- 공유 코드·클라이언트·Worker 타입 검사 통과.
- 모바일 HUD 브라우저, 리소스 예산, 새 설치 오프라인, 업데이트 거부/정상 교체/롤백 검사 통과.

전체 루트 검사에서 발견한 통합 누락은 수정 후 해당 단계 및 후속 전체 테스트를 재실행했다. 사진 효과 높이는 예전 60~66px 범위 대신 새 규격의 정확한 54px로 검사한다. 깨끗한 체크아웃에서도 앵커 검사 전에 자산을 생성한다. CI 월간 통계 테스트의 날짜만 기존 8월 표본으로 고정했다(서비스 로직 변경 없음).

## 재현성 및 배포 상태

`list-guest216-release-inputs.mjs`로 원본과 검수 자료만 선별했다. 전체 556개 원본 참조가 포함됨을 확인했다. 재생성 가능한 약 3GB의 내장 이미지 SVG 중간 출력은 Git 대상에서 제외한다. 별도 검증 복사본은 독립 `pnpm install --frozen-lockfile`로 설치했으며 사용자 작업 디렉토리나 node_modules를 공유하지 않는다.

이 문서를 처음 작성한 시점에는 독립 프로덕션 빌드와 원격 CI/PR/Pages 배포가 아직 진행 전 또는 검사 중이다. 로컬 브라우저의 `production-preview` 명칭은 운영 배포 성공을 뜻하지 않는다. 최종 커밋·PR·배포 실행·운영 해시 및 서비스 워커 갱신 결과는 실제 확인 후 별도 기록한다.
