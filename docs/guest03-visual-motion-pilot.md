# 3번 로컬 화면 이동 보간 — 2026-09-08

## 적용 범위

`VITE_GUEST03_PILOT=true`인 개발 서버의 네이비 클래식 수트에만 적용한다. 원화, 파츠, 16프레임 PNG 및 다른 11명은 변경하지 않았다. 충돌·포털·네트워크가 읽고 쓰는 기존 motionStore와 타일 좌표도 그대로다. 커밋·푸시·운영 배포 없음.

별도 표시 store가 승인된 타일 경로를 125px/s로 따라가며, 로컬 캐릭터와 카메라는 같은 표시 store를 구독한다. 모서리는 대각선 지름길로 보간하지 않고 입력된 경로 순서대로 이동한다. 화면 진행 방향으로 캐릭터를 향하게 하며, 키를 놓으면 이미 승인된 이동을 끝낸 후 중립 프레임으로 정지한다. 순간이동·구역 변경·백그라운드 복귀 시 표시 경로를 초기화한다.

보행 위상은 실제 표시 이동 거리 30px마다 진행한다. 타일 경계에서 강제로 중립으로 되돌리는 현상은 제거했다. **이는 기존 960ms/120px 주기의 거리 기반 재생이며, 원화 발의 접지 거리와 일치한다는 뜻은 아니다.** 접지 구간 정의와 보폭의 추가 시각 검토가 필요하다. 논리 위치보다 화면이 최대 한 이동 구간 정도 늦게 따라가는 동작도 사용자 검토 대상이다.

## 검증

- 유닛 테스트: 보간 속도/논리 좌표 보존, 정지, 모서리, 반전, 순간이동·초기화, 백그라운드 복귀 6개 통과.
- 전체 클라이언트 259파일 / 1,362테스트 통과. 타입 검사 및 프로덕션 빌드 통과.
- 프로덕션 JS에 `__guest03-pilot`, `integrated-v2` 경로 미포함.
- agent-browser 실제 GameWorld 390×844, 조이스틱 상하좌우 입력, 각 1,050ms 이동 후 350ms 정지. DOM/React 위치 강제 변경 없음.
- 최종 rAF 샘플: 위 122개, 아래 123개, 왼쪽 121개, 오른쪽 124개. 샘플 간 최대 표시 위치 변화는 각각 3.425 / 3.400 / 3.413 / 3.413px. 이전 측정은 네 방향 모두 30px. 이 수치는 샘플 간격에 의존하며 고정 1px 이하 품질 판정 기준이 아니다.
- 네 방향 모두 4개 프레임 관찰, 마지막에는 해당 방향 유지·중립 2번·moving=false 확인.
- 이전 측정 프로브에서 종료 직후 예약된 rAF가 다음 방향 샘플을 추가할 수 있어, 종료 시 cancelAnimationFrame을 추가했다. 기존 baseline 데이터는 수정하지 않았다.

최종 원시 샘플: `character-assets/rigs/guest-03/style-lock-cutout-v1/animation/integrated-v2/smooth-contact-samples.json`.

## 남은 사항

48×72 실제 맵 화면의 정지/이동 캡처를 확인했다. 그러나 정지 이미지와 수치만으로 보행 시각 품질 전체를 승인하지 않는다. 연속 재생에서 발의 접지·보폭과 입력 해제 후 따라오는 느낌을 사용자와 확인해야 한다. 84/168/252 신체 규격, 전체 맵·실기기 터치·나머지 캐릭터 확대 적용 및 운영 검증은 이번 단계에서 완료하지 않았다. 기존 접지/캐시 감사 문서는 이전 단계 기록으로 보존한다.
