## 배포 준비 재검수

최신 일반 빌드의 선택 화면 48장(12명 × 정면·왼쪽·오른쪽·후면)을 실제 표시 배율 그대로 화면 영역만 모아 `common-three-head-216-v1/release-review/selection-{1,2,3}.png`로 확인했다. 목·어깨의 뚜렷한 단절, 머리 크기의 방향별 급변, 크림색 의상의 소실은 보이지 않았다. 가방은 앞에서 화면 오른쪽, 뒤에서 왼쪽에 유지되며 반대 측면에서는 신체 뒤로 가려진다. 확대된 미리보기의 발은 동일한 바닥에 놓인다. 정지 화면 검수이며 보행은 아래 기존 동일 원본 검수 및 실제 UI 보행 관측과 구분한다.

사용자가 위임한 판단 범위에서 의도한 원화 전환을 승인하여 모바일 게임 시각 기준을 갱신했다. 이전 기준·실패 비교는 `release-review/legacy-baseline/`에 원본 해시와 함께 보존했다. 맵 10영역은 변경되지 않았고 차이는 캐릭터 영역이었다. 어떤 회귀 허용치도 넓히지 않았다. 아래의 “아직 교체하지 않았다”는 당시 기록이며 현재 상태가 아니다. 운영 배포 성공 및 운영 캐시 갱신은 별도 릴리스 검증 전까지 주장하지 않는다.

## 일반 빌드 연결 후 추가 관찰

`local-selection-216-production-preview-down.png` 12명을 모두 직접 열었다. 선택 UI에 동일한 외형과 3등신이 유지되며 밝은 옷의 큰 소실이나 목·어깨의 눈에 띄는 단절은 보이지 않는다. 3번의 일반 게임 네 방향 화면도 열었으나 왼쪽 얼굴 위에는 맵 상호작용 아이콘이 일부 겹친다. 이 캡처를 얼굴 전체 검수 증거로 보지 않는다.

일반 빌드의 전체 12명 × 선택/게임 × 네 방향 보행·정지는 실제 UI 입력과 JSON/PNG 해시로 재검사했다. 이 자동 동작 검증은 측면/후면 캡처를 전부 다시 눈으로 봤다는 뜻이 아니다. 아래 이전 단계의 동일 원본 검수 기록은 유지한다.

최신 브라우저 맵 자료는 배경·전경·측정 코드까지 해시를 묶어 재수집했다. 이전 40장 검토 이후 화면·원본을 바꾸지 않은 provenance 보강이며, home 정면/후면 및 lobby 왼쪽/bridal-room 오른쪽을 다시 직접 확인했다. 새 회귀 기준은 이 검수 이력을 명시하고 기존 대비 허용치를 유지한다. 기존 모바일 시각 기준 이미지는 아직 교체하지 않았다.
