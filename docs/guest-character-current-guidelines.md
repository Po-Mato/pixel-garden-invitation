# 하객 캐릭터 현재 지침

## 2026-09-10 추가 요청: 선택 미리보기 중심·크기

- 원본 72/144/216 골격, PNG 및 게임 48×72 표시는 변경하지 않는다.
- 기본 미리보기 프레임 계약 96×144 위에 선택 모달 전용 배율을 적용한다. 390×844에서는 160×240 캔버스(실제 인물 높이 180px), 높이 800px 이하에서는 128×192(인물 144px)로 표시한다.
- x=96 중심과 y=270 발선을 기준으로 정렬한다. 방향별/프레임별 픽셀 외곽을 따라 재중심화하지 않는다. 등장 애니메이션은 배율을 덮어쓰지 않는다.
- 짧은 화면에서는 미리보기 최소 공간을 확보하고 모달 내부 스크롤로 나머지 입력/선택 항목에 접근한다.
- 이 선택 모달 표시 변경은 아래 이전 96×144 고정 표시 지침보다 우선하며, 원본 자산 규격 변경은 아니다.

## 2026-09-10 사용자 확정: 정확한 3등신 골격

최신 요청은 **머리 72px·몸 144px·전체 216px**로 골격까지 변경하는 것이다. 아래 2026-09-09의 외형 보존·몸 높이 미확정 조건보다 우선한다. 세부 구현 판단은 에이전트에게 위임되었다.

- 공용 편집 원본: `character-assets/rigs/common-three-head-216-v1/skeleton.json`.
- 192×288 캔버스, 중심 x=96, 발 기준선 y=270. 머리 y=54–126, 몸 y=126–270.
- 선택 96×144, 게임 48×72, 보행 시트 768×1152는 유지한다.
- 이전 리그와 검수본은 보존한다. 원본 파츠 배치·피벗·의상별 키프레임을 새 골격에 연결하고 다시 렌더링한다. 출력 PNG의 머리·몸통·발 영역을 보정하지 않는다.
- 새 골격의 수학적 규격과 실제 알파 외곽·관절 연결·시각 품질을 따로 검증한다. 선언 값만으로 실제 캐릭터의 검수 통과를 주장하지 않는다.
- 기존 검수·테스트·해시는 새 출력의 승인 증거가 아니다. 새 프레임·브라우저·맵·서비스 워커 검증을 다시 수행한다.

## 2026-09-09 사용자 승인 변경

사용자 요청: “72px로 지침 변경”. 현재 승인한 3번 외형을 유지하며, 하객 머리 높이 기준을 기존 84px에서 **72px**로 변경한다. 이전 문서의 84px 지침보다 이 변경이 우선한다.

- 측정 기준: 192×288 프레임에서 정면 머리 파츠 배치 범위(투명 여백 포함). 현재 3번은 y=26~98, 하단 제외, 높이 72px.
- 선택 화면 96×144에서 대응 높이 36px, 게임 화면 48×72에서 18px.
- 불투명 픽셀만 측정한 머리 높이가 정확히 72px라는 뜻은 아니다.
- 원화, 파츠 위치·크기, 애니메이션, 최종 PNG는 변경하지 않는다.
- 측면·후면은 승인된 외형을 유지하며 정면과의 시각적 일관성을 별도 검사한다. 이번 변경으로 모든 방향의 픽셀 높이가 검증된 것은 아니다.
- 프레임 192×288, 보행 시트 768×1152, 선택 표시 96×144, 게임 표시 48×72는 유지한다.

이번 승인은 머리 높이에 한정된다. 기존 몸 168px·전체 252px 선언을 검증 완료로 취급하지 않으며, 몸 높이를 144px 또는 전체 높이를 216px로 임의 변경하지 않는다. 정확한 3등신 여부와 몸·전체 높이의 정합성은 별도 미해결 사항이다. 원본 기반 제작·비대칭 방향 보존·개별 시각 검수·최종 승인 후 배포 원칙은 유지한다.
